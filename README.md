# Kashie: Your Daily Cash Friend

Build a simple chat-based web app called Kashie for small business owners to track and understand their daily finances.

The app should feel like chatting with a friendly finance assistant, not an accountant.

Core features:

1. Daily Money Logging:

- Ask the user: "How much did you make today?"

- Then ask: "How much did you spend today?"

- Calculate profit = revenue - expenses

2. Simple Explanation:

- After calculating profit, explain it in very simple terms

- Be encouraging and supportive

- Give 1 short practical suggestion

3. Weekly Summary:

- When the user asks for a summary, show:

  - Total revenue

  - Total expenses

  - Total profit

- Then explain what it means in simple language

Tone:

- Friendly, simple, non-technical

- Like talking to a helpful business friend

- No accounting jargon

UI:

- Clean chat interface

- Minimal design (similar to WhatsApp)

- Include quick buttons:

  - "Log today's money"

  - "Weekly summary"
